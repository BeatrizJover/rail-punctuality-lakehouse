# Belgian Rail Punctuality Lakehouse

A data engineering portfolio project built with Databricks using Belgian railway punctuality open data.

## Project Status

🚧 **In development**

The project is being built incrementally, following a production-oriented data engineering workflow.

## Objective

Build a reproducible lakehouse platform for analysing Belgian railway punctuality data, from raw ingestion to analytics-ready datasets.

## Planned Architecture

* Infrabel Open Data
* Databricks
* Unity Catalog
* Delta Lake
* Medallion Architecture
* PySpark
* Databricks SQL
* Power BI
